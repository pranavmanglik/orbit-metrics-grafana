# Security policy

Do not publish vulnerability details in public issues. Use GitHub Security Advisories for this repository, or contact maintainers privately through the hosting platform if private reporting is unavailable. Include the affected version or commit, impact, a safe reproduction, and mitigations. Redact credentials, personal data, private keys, and production endpoints.

This plugin is in alpha and has no stable-release or response-time commitment. Local checks do not certify Grafana configuration, Prometheus security, Orbit scrape-route authorization, or deployment network controls.
